# License, provenance and confidentiality checklist

- Confirm the owner, existing project license and intended distribution/use; preserve them unless explicitly changed by the owner.
- Apply CONVENTIONS.md (Licensing and provenance). Inventory exact direct/transitive dependencies, development tools and code copied/generated by them; include source/assets/documents outside dependency managers.
- Verify origin, actual license texts and copyright holders, modification status, SPDX choices and contractual/paid rights. Missing license or a public repository is not permission. Do not treat package metadata or AI output as proof of all rights.
- Evaluate obligations for the actual use: LICENSE/NOTICE/attribution, modification notices, source or source offers, network use and redistribution. Investigate unclear/copyleft/custom/multiple licenses instead of automatically approving or banning them.
- Inspect the actual installable ZIP and separately delivered documents: required complete license/notices and relevant source obligations must survive the runtime-only packaging policy. Check whether development tools contributed shipped code.
- Bind evidence and conclusions to the exact commit, dependency locks and artifact hash. Review relevant changes again; preserve the original findings and their resolution history.
- Mark unresolved relevant obligations as blocking release. Ask a concrete owner question or obtain qualified legal assessment where necessary. Never invent rights, approval or an exception. A successful inventory command is not legal certification.
- Keep customer secrets, credentials and private keys out of code, reports and documentation. Keep confidential entitlement/contract evidence private and record only a safe reference in public material.
- Ensure external API usage notes do not disclose confidential integration data. Describe the actual scope and limits of any legal/compliance review.

Sources: [SPDX expressions](https://spdx.github.io/spdx-spec/v2.3.1/SPDX-license-expressions/), [Composer license metadata](https://getcomposer.org/doc/04-schema.md#license), [MIT](https://opensource.org/license/mit), [AFL-3.0](https://opensource.org/license/AFL-3.0).
